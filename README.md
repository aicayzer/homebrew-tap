# homebrew-tap

Homebrew formulae and casks for my own tools and apps.

```bash
brew install aicayzer/tap/runpool
brew install --cask aicayzer/tap/memos
```

## Formulae

- **[runpool](https://github.com/aicayzer/runpool)** — on-demand self-hosted GitHub Actions runner pools for macOS.
- **[sessionmail](https://github.com/aicayzer/sessionmail)** — local, paired mailbox for AI coding agents that can't otherwise reach each other.

## Casks

- **[memos](https://github.com/aicayzer/memos)** — a small native notes window that floats above whatever you are doing, with its command line tool.
